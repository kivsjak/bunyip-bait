# Bunyip Bait — прототип слота (Stake Engine)

Кластерний слот 6×5 на Pixi 7. Розібраний з однофайлового `reference/prototype_original.html`
(оригінал лежить там як еталон, не правити).

```
npm install
npm run dev        # http://localhost:5180
npm run build      # dist/ — статика для Stake Engine (base: './')
```

Параметри URL: `?lang=ru` · `?currency=EUR` · `?sessionID=…&rgs_url=…` — справжній RGS.
Без `sessionID` гра грає на моку: раунди беруться з `public/books/<режим>.json`.

## Структура

| де | що |
|---|---|
| `src/game/` | логіка без рендеру: `rgs.ts` (RGS + мок), `i18n.ts` (тексти, гроші), `symbols.ts` + `pays.json` (символи, виплати) |
| `src/render/assets.ts` | **список усіх картинок** + завантаження + скін DOM |
| `src/render/scene.ts` | Pixi: поле, символи, плями прикормки, бейджі множників, розкладка |
| `src/render/events.ts` | анімація подій книги (reveal, tumble, chomp, фриспіни…) + репліки маскотів |
| `src/render/anim.ts` | tween / паузи / турбо |
| `src/main.ts` | кнопки, раунд, старт |
| `public/assets/` | PNG-ассети |
| `public/books/` | мок-раунди |

## Як підмінити графіку

Покласти PNG з потрібним ім'ям у `public/assets/…` і перезавантажити сторінку. Код не чіпати.
**Нема файлу → малюється як у прототипі** (кодом або CSS), тож слоти можна заповнювати по одному.

| файл | що це | розмір зараз / рекомендовано | як вставляється |
|---|---|---|---|
| `bg/background.png` | фон сцени | 1280×800 | `cover`, по центру зверху |
| `symbols/H1..H4, L1..L4, S.png` | символи (Barra, Cod, Yabby, Eel, Tinny, Pie, Thong, Boot, Cooler) | 240×240 | квадрат 94% клітинки |
| `characters/yeti.png`, `yeti_hyped.png`, `kev.png`, `kev_hyped.png` | маскоти, спокій / ажіотаж | 300×390 | ширина по місцю, низ по краю |
| `ui/frame.png` | рамка поля | ~1248×1048 (пропорція 6.24 : 5.24) | розтягується на поле + 12% клітинки з кожного боку |
| `ui/burley_spot.png` | пляма прикормки під символом | ~210×190 | 84%×76% клітинки |
| `ui/mult_badge.png` | підкладка бейджа ×N | ~168×136 | 42%×34% клітинки; цифру малює код поверх |
| `ui/bunyip_eyes.png` | очі буньїпа, що виринають при «укусі» | ~280×140 | 70%×35% клітинки |
| `ui/logo.png` | лого замість тексту «Bunyip Bait» | будь-яка ширина | висота 44–90 px |
| `ui/hud_bar.png` | нижня панель | широка смуга | розтягується 100%×100% |
| `ui/btn_spin.png` | кнопка Spin | 156×156 | кругла 78 px, розтягується |
| `ui/btn.png` | звичайні кнопки (−, +, Burley, Turbo, Rules, Close, Cancel) | — | розтягується 100%×100% |
| `ui/btn_buy.png` | Buy bonus / Super bonus / OK | — | розтягується 100%×100% |
| `ui/bubble.png` | бульбашка реплік | — | розтягується |
| `ui/fs_bar.png` | плашка «Free spin N of M» | — | розтягується |
| `ui/dialog.png` | фон вікон правил / підтвердження | — | розтягується |

Текст на кнопках, у бульбашках і на бейджах лишається живим (переклади, ціни) — у PNG його не малювати.
Новий слот: дописати рядок у `ASSETS` у `src/render/assets.ts` і використати `tex()` / `url()`.
